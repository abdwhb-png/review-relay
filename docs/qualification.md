## Release gate

Complete both hosted paths against the frozen runtime candidate before tagging. Keep consumer evidence private and verify publication on the exact reviewed commits. Any runtime, workflow, native profile or dependency change invalidates the affected qualification and requires a new candidate. A release commit may add only documentation of completed evidence; verify that its executable files and configuration are identical to the qualified candidate before creating the version tag. Neither an approved design nor local fixture results alone establish a qualified release.
